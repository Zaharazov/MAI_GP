# Игра с двумя механиками
#### Выполнил: Епифанов Евгений, группа М8О-412Б-22

Механики:
1) Светочувствительность игрока. Тени от объектов на сцене выступают в роли препятствий для игрока.
2) Манипуляция источниками света для выстраивания теневых рисунков на поверхностях, через которые игрок сможет пройти

Управление: 

- Движение игрока - WASD

- Прыжок - Space

- Перемещение источников света - OP
